# Pathie

**複製路徑，就打開它。**

同事在聊天室貼了一串 `R:\專案\2026\交件`，你不用再打開檔案總管、一層一層點進去。只要按下 Ctrl+C，Pathie 就幫你把那個資料夾打開。

<!-- 示意圖：主視覺。在聊天軟體選取一段路徑 → Ctrl+C → 檔案總管自動跳出該資料夾，右下角出現「由 Pathie 開啟」 -->

Pathie 是一個常駐在 Windows 系統匣的小工具，安靜地看著你的剪貼簿：複製到的是有效的資料夾、檔案路徑或網址，就自動幫你開啟；複製一般文字，它什麼都不做。

## 特色

- **複製即開啟**：資料夾、檔案路徑、`http(s)` 網址都認得，不用貼到任何地方。
- **預設就安全**：檔案只會在檔案總管裡幫你選取，不會直接執行；可疑的網路路徑、執行檔都有把關。詳見下方〈[安全設計](#安全設計)〉。
- **不打擾**：沒開東西時完全不出聲，開了東西只在角落輕輕提示一下。
- **輕巧**：安裝檔只有幾 MB，不需要系統管理員權限。

## 下載與安裝

1. 到 [Releases 頁面](https://github.com/YuCMochi/Pathie/releases/latest) 下載 `Pathie-Setup.exe`。
2. 執行安裝程式。不需要系統管理員權限，安裝過程中可以勾選「開機自動啟動」。
3. 安裝完成後 Pathie 會自動啟動，第一次會打開「使用說明」頁。

之後 Pathie 就待在螢幕右下角的系統匣裡（可能收在 `^` 箭頭裡面）。

> **系統需求**：Windows 10 或 11。設定視窗需要 Microsoft Edge WebView2 Runtime，大多數電腦已經內建；如果沒有，安裝程式會提醒你並附上下載連結。

## 怎麼用

**複製就好。** 不管是在聊天軟體、Email、文件還是任何地方，選取一段路徑或網址按 Ctrl+C，Pathie 就會處理。

| 你複製了… | Pathie 會… |
|---|---|
| 資料夾路徑，例如 `D:\照片\2026` | 在檔案總管打開這個資料夾 |
| 檔案路徑，例如 `D:\報告\期末.docx` | 打開所在資料夾，並選取這個檔案（不會直接開啟它） |
| 網址，例如 `https://example.com` 或 `www.example.com` | 用預設瀏覽器打開 |
| 一般文字、不存在的路徑 | 什麼都不做 |

開啟成功時，螢幕右下角會短暫出現「由 Pathie 開啟」，讓你知道剛剛跳出來的視窗是從哪來的。

<!-- 示意圖：右下角「由 Pathie 開啟」浮窗截圖 -->

Pathie 也看得懂這些寫法：

- 前後加了引號的路徑：`"C:\Program Files\App"`
- 正斜線：`C:/Users/me/Desktop`
- `file:///` 開頭的網址形式
- 含環境變數的路徑：`%USERPROFILE%\Downloads`、`%TEMP%`
- 一次複製多行時，只看第一行

### 系統匣操作

- **左鍵點圖示**：暫停／恢復（暫停時圖示會變灰）。要複製很多路徑又不想被一直開視窗時很好用。
- **右鍵點圖示**：暫停／恢復、開啟設定、退出。
- 滑鼠停在圖示上可以看到目前版本。

## 安全設計

自動開啟東西聽起來有點危險，所以 Pathie 預設就很保守：

- **只認完整路徑**：一定要是像 `C:\...` 這樣從磁碟機開始的完整路徑才會開。單獨的檔名（例如 `gpedit.msc`）或相對路徑一律忽略，避免誤觸系統指令。
- **檔案不會被執行**：複製檔案路徑時，預設只在檔案總管中選取它。就算你改成「直接開啟」，`.exe`、`.bat`、`.ps1`、`.lnk`、`.msi` 等執行檔與腳本仍然只會被選取，不會執行。
- **網路路徑預設不處理**：像 `\\server\share` 這種網路位置，Windows 光是去檢查它存不存在，就可能把你的登入憑證雜湊送給對方伺服器。所以 Pathie 預設略過，需要時可以在設定裡開啟。
- **網址只認 `http://`、`https://`、`www.`**：其他協定（可能被用來呼叫系統功能）和沒有前綴的網域（如 `example.com`）都不處理。
- **從瀏覽器複製的網址不會再開一次**：你在瀏覽器裡複製網址，多半是要貼給別人，不是要再開一個分頁。所以複製當下如果前景是 Chrome、Edge、Firefox、Brave、Opera、Vivaldi、Zen、Arc 或 Dia，網址就會略過。
- **防止視窗洪水**：如果一分鐘內被要求開啟太多次（預設 20 次），Pathie 會自動暫停並通知你，避免有程式惡意或失控地狂複製路徑。左鍵點圖示即可恢復。

## 設定

右鍵系統匣圖示，選「設定…」。

| 分頁 | 可以調整 |
|---|---|
| 一般 | 監控剪貼簿開關、開機自動啟動 |
| 檔案與網址 | 複製檔案路徑時要「不處理」、「在資料夾中選取」（預設）或「直接開啟」；是否自動開啟網址；從瀏覽器複製的網址是否略過 |
| 安全 | 是否處理網路路徑；每分鐘開啟上限（10／20／50／100 次） |
| 提示 | 開啟成功時是否顯示「由 Pathie 開啟」 |
| 使用說明 | 第一次啟動時看到的那份說明，隨時可以回來看 |

設定會自動儲存，不用按確定。

## 常見問題

**關掉設定視窗之後 Pathie 就沒在跑了嗎？**
還在。關掉視窗只是收起來，Pathie 仍在系統匣。要完全結束，右鍵圖示選「退出」。

**我複製了路徑，但沒有反應？**
先確認系統匣圖示不是灰色的（灰色代表暫停中，左鍵點一下恢復）。再確認那是完整路徑、而且真的存在；網路路徑（`\\` 開頭）預設不處理。

**我只是想把網址複製給朋友，結果它一直開新分頁。**
從瀏覽器複製的網址預設就會略過。如果是從其他地方複製的，可以暫時左鍵點圖示暫停，或在「檔案與網址」關閉「自動開啟網址」。

**重複打開 Pathie 會怎樣？**
不會跑出第二個。Pathie 會通知你它已經在執行中，並告訴你目前是否在監控。

**Windows 跳出「Windows 已保護您的電腦」？**
這是 Windows 對較少人下載的程式的通用提醒。點「其他資訊」→「仍要執行」即可。

**要怎麼更新？**
下載新版的 `Pathie-Setup.exe` 直接安裝就好，設定會保留。安裝程式偵測到 Pathie 正在執行時，會請你先關掉它。

**要怎麼解除安裝？**
到 Windows「設定 → 應用程式」找到 Pathie 解除安裝。設定檔和開機自動啟動也會一併清除，不會留下東西。

## 給開發者

以 Rust + [Tauri 2](https://tauri.app/) 實作，設定視窗為 React + Tailwind + shadcn/ui。產出單一 exe（約 3–4 MB），不需要 .NET runtime。

### 建置

需要 [Rust](https://rustup.rs/)、MSVC build tools 與 [Node.js](https://nodejs.org/)：

```
npm install
npm run tauri -- build --no-bundle
```

產物在 `src-tauri/target/release/Pathie.exe`。開發時請用 `npm run tauri -- dev`（debug 版會連 Vite 開發伺服器，直接執行 `target/debug/Pathie.exe` 或 `cargo run` 會顯示「localhost 拒絕連線」）；啟動時加 `--settings` 會直接開啟設定視窗。

打包安裝程式（需要 [Inno Setup 6](https://jrsoftware.org/isinfo.php)，先照上面建置出 exe）：

```
ISCC /DAppVersion=<src-tauri/Cargo.toml 的版本號> installer.iss
```

產物在 `dist/Pathie-Setup.exe`。

### 測試

```
cd src-tauri
cargo test
```

### 技術細節

- 設定存在 `%APPDATA%\Pathie\settings.json`。從 0.2.x 以前（存在登錄檔 `HKCU\Software\Pathie`）升級時，首次啟動會自動搬入。0.1.x 的「僅開啟資料夾」設定不會沿用，升級後回到「在資料夾中選取」。
- 「直接開啟」仍會擋下的副檔名完整清單見 `src-tauri/src/logic.rs` 的 `DANGEROUS_EXTS`；瀏覽器清單見 `BROWSERS`（比對程序名稱，不分大小寫）。
- 「從瀏覽器複製」的判斷依據是複製當下的前景視窗，不是剪貼簿來源。
- 網路路徑在碰檔案系統之前就擋掉，因為 `exists()`／`is_dir()` 本身就會觸發 SMB 連線並可能送出 NTLM hash。
